◷

There is no calendar day-gate. "Done today" is derived from attempts only — after a normal advance the hero immediately offers Day N+1, so a student can complete several "days" in one sitting. The only "come back tomorrow" is the server hold-csd (throttle / non-engaged). KST clocks exist solely in streaks and challenge-token weeks. Any real daily cap would be new behavior.
